Temas y explicaciones

¿Qué es programar?

Programar es escribir instrucciones para que una computadora o microcontrolador resuelva tareas. Un algoritmo es una serie ordenada de pasos. Ejemplo: pedir dos números, sumarlos y mostrar el resultado.

Java y JCreator

Java es un lenguaje de programación. JCreator es un entorno de desarrollo que permite escribir, compilar y ejecutar programas Java. En consola, javac Hola.java compila el archivo y java Hola ejecuta la clase, siempre que el JDK esté instalado y configurado.

Operadores aritméticos

En Java: + suma, - resta, * multiplicación, / división y % residuo. Ejemplo: 10 % 3 produce 1. Si divides enteros, 5 / 2 da 2; usa 5.0 / 2 para obtener 2.5.

Visual Studio y ejercicios

Visual Studio permite crear proyectos en lenguajes como C#. En una aplicación de consola puedes leer valores con Console.ReadLine(), convertirlos con double.Parse() y mostrar resultados con Console.WriteLine(). Practica sumando dos números, cuatro números y calculando el promedio de cuatro parciales.

Arduino

Arduino es una plataforma de hardware y software para proyectos electrónicos. Un programa Arduino tiene setup(), que se ejecuta una vez, y loop(), que se repite. Ejemplo: encender y apagar el LED integrado de una placa compatible usando LED_BUILTIN. Para componentes externos, utiliza resistencias adecuadas y conexiones de bajo voltaje.

Buenas prácticas

Usa nombres claros, indenta el código, agrega comentarios breves, comprueba las entradas y prueba varios valores. Un error de sintaxis impide compilar; un error lógico puede dar resultados incorrectos aunque el programa se ejecute.

Ejemplos prácticos

Estos ejemplos ayudan a entender lo aprendido en clase.

Java: sumar dos números

public class Suma {
  public static void main(String[] args) {
    int a = 8, b = 5;
    System.out.println("Suma: " + (a + b));
  }
}

C#: suma de dos números

double a = 8, b = 5;
Console.WriteLine("Suma: " + (a + b));

C#: suma de cuatro números

double a = 2, b = 4, c = 6, d = 8;
Console.WriteLine("Total: " + (a+b+c+d));

C#: promedio de cuatro parciales

double p1 = 80, p2 = 90, p3 = 75, p4 = 95;
double promedio = (p1+p2+p3+p4)/4.0;
Console.WriteLine("Promedio: " + promedio);

Arduino: LED integrado

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
