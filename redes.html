Redes de informática

Conexiones, direcciones IP y dispositivos que permiten compartir información.

← Volver al inicio

Temas y explicaciones

¿Qué es una red?

Una red informática conecta dos o más dispositivos para compartir datos, archivos, impresoras o acceso a internet. Ejemplo: los celulares y computadoras conectados al Wi-Fi de la casa.

LAN, WAN, MAN y PAN

LAN: red de área local, como el laboratorio de informática. WAN: conecta redes a grandes distancias, como las sedes de una empresa en distintos países. MAN: abarca una ciudad, como una red municipal. PAN: conecta dispositivos personales cercanos, por ejemplo, un teléfono con audífonos Bluetooth.

La red más grande del mundo

Internet es la red de redes más grande del mundo: conecta millones de redes públicas y privadas. La Web (WWW) es uno de los servicios que funciona sobre internet; no son exactamente lo mismo.

IP y protocolo de internet

Una dirección IP identifica una interfaz dentro de una red. IPv4 utiliza cuatro números separados por puntos, por ejemplo 192.168.1.10. IPv6 usa una notación más larga, como 2001:db8::1. El protocolo IP permite direccionar y enviar paquetes entre redes. TCP ayuda a entregar datos de forma fiable; UDP se usa cuando importa la rapidez.

DHCP, DNS y puerta de enlace

DHCP asigna automáticamente una dirección IP y otros parámetros al conectarse a una red. DNS traduce nombres como ejemplo.com a direcciones IP. La puerta de enlace predeterminada suele ser el router que comunica la red local con otras redes.

Topologías de red

Estrella: todos los equipos se conectan a un dispositivo central; si falla un cable, normalmente solo se afecta un equipo. Bus: varios equipos comparten un medio principal. Anillo: los dispositivos forman un circuito. Malla: existen varias rutas entre nodos. Árbol: combina niveles de conexión.

CMD e ipconfig

En Windows presiona Win + R, escribe cmd y Enter. Ejecuta ipconfig para ver IPv4, máscara y puerta de enlace. ipconfig /all muestra más detalles; ping 8.8.8.8 comprueba conectividad; ping ejemplo.com ayuda a comprobar también la resolución de nombres. No cambies configuraciones que no conozcas.

Cómo conectar un router

1. Conecta el router a la corriente. 2. Conecta el cable del módem/ONT al puerto WAN del router, si corresponde. 3. Conecta una computadora por Ethernet o a la red Wi-Fi inicial. 4. Abre la dirección de administración indicada en la etiqueta o manual. 5. Cambia la contraseña de administrador, configura nombre de red y seguridad WPA2/WPA3. 6. Guarda, reconecta los equipos y prueba internet. Los pasos varían según el modelo.
